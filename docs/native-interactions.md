# Нативные опросы и реакции

Обычный опрос MAX отправляется через `sendPoll` в соответствующий топик.
Выбор владельца приходит как `poll_answer`, проверяется по сохранённому `poll_id`
и отправляется в исходный MAX-опрос через `vote_poll`.

Счётчики Telegram относятся к локальному опросу: Bot API не позволяет импортировать
голоса участников MAX. Кнопка **«Результаты MAX»** показывает последний снимок
результатов и ставит обновление в очередь.

Если вопрос или варианты изменились, создаётся новый Telegram-опрос. Закрытие
оригинала закрывает локальный опрос. Типы, которые нельзя представить нативно
без искажения (например, викторина без известного правильного ответа), показываются
как обычное текстовое сообщение без интерактивных кнопок.

Опрос, созданный пользователем в Telegram, отправляется в MAX без второй копии
в том же топике.

Реакция MAX переносится через `setMessageReaction`, только когда одна реакция
может быть показана без ложного счётчика. Telegram не позволяет боту расставить
реакции от имени участников MAX. В обратную сторону обрабатываются доступные
боту `message_reaction` updates.

Контракты: [Update](https://core.telegram.org/bots/api#update),
[sendPoll](https://core.telegram.org/bots/api#sendpoll),
[PollAnswer](https://core.telegram.org/bots/api#pollanswer),
[setMessageReaction](https://core.telegram.org/bots/api#setmessagereaction).
