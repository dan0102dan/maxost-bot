# Нативные опросы и реакции

Обычный опрос MAX отправляется через `sendPoll` в соответствующий топик.
Локальная копия неанонимная и защищена от пересылки: событие `poll_answer`
проверяется по владельцу и сохранённому `poll_id`, затем выбор попадает в очередь
для `vote_poll` исходного MAX-опроса. Анонимность исходного опроса MAX не меняется.
Повторная доставка Telegram update не создаёт второе задание.

Счётчики Telegram относятся к локальному опросу. Bot API не позволяет записать
в них голоса участников MAX. Кнопка «Результаты MAX» показывает последний
сохранённый результат и запрашивает обновление; следующий просмотр покажет
обновлённые данные. Успешный голос тоже обновляет снимок. При недоступном MAX
доставка голоса остаётся в очереди, поэтому локальный выбор ещё не означает,
что MAX принял голос.

Закрытие оригинала закрывает локальную копию при следующем обновлении.
Изменение вопроса или вариантов создаёт новый опрос; старые голоса не попадут
в новые варианты. Викторины без известного правильного ответа и опросы за
пределами лимитов Telegram остаются карточками — без выдуманных ответов или
обрезанных вариантов. Опрос, созданный пользователем в Telegram, отправляется
в MAX без дополнительной копии в Telegram. Голоса в таком пользовательском
опросе Bot API не передаёт боту.

Единственная реакция другого участника MAX отображается через
`setMessageReaction` от имени бота. Несколько реакций и их точные счётчики
остаются компактной сводкой: бот не может расставить их от имени других людей.
Обработчик `message_reaction` готов к событиям Telegram, но Bot API требует
права администратора чата для их получения: обычные личные топики не дают
полноценного обратного потока. Кнопки существующих карточек остаются рабочими;
команды `/react` и `/poll` скрыты из меню и справки, старые вызовы совместимы.

Контракты: [Update](https://core.telegram.org/bots/api#update),
[sendPoll](https://core.telegram.org/bots/api#sendpoll),
[PollAnswer](https://core.telegram.org/bots/api#pollanswer),
[setMessageReaction](https://core.telegram.org/bots/api#setmessagereaction).
