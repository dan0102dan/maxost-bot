# Эксплуатация

## Проверка перед открытой регистрацией

Сначала задайте `ALLOWED_TELEGRAM_IDS` для двух тестовых пользователей. Проверьте
вход по SMS/QR, личные чаты, группы и каналы, файлы, альбомы, опросы, редактирование,
отзыв сессии и восстановление после перезапуска.

Стикеры Telegram уходят в MAX исходным документом. Текст и подпись не содержат
служебных приписок: неподдерживаемое оформление не меняет сам текст.

## Ошибки доставки

Под ошибкой есть две кнопки: синяя **«Повторить»** и красная **«Пропустить»**.
При неизвестном результате повтор требует отдельного подтверждения: сообщение
могло уже дойти. Подтверждённые части отправки повторно не отправляются.
Кнопки доступны только владельцу и продолжают работать после перезапуска.
Повторные нажатия и кнопки предыдущей попытки не запускают новую отправку.

Ошибка или отложенный повтор **MAX → Telegram** не задерживает следующие
сообщения. Для направления **Telegram → MAX** порядок сохраняется до повтора
или пропуска проблемного сообщения. В обоих направлениях уже выполняющаяся
отправка не запускается параллельно с ручным повтором в том же диалоге.

`/status` показывает состояние и ненулевые счётчики. Если создание топика
завершилось неопределённо, привяжите существующий топик через `/bind UUID`,
затем нажмите **«Повторить»** под ошибкой.

## Автотесты

```bash
python -m pip install . -r requirements-dev.txt
ruff check maxost tests
pytest -q
```

PostgreSQL-тесты требуют **одноразовую тестовую БД** через `TEST_DATABASE_URL`:
они очищают тестовые данные. CI использует PostgreSQL 17 и собирает Docker.
Живые аккаунты, SMS и пользовательские токены в CI не используются.

## Резервные копии

Сохраняйте PostgreSQL и `.env` отдельно. В `ENCRYPTION_KEYS` первый ключ шифрует
новые записи, остальные читают существующие; последний также используется для
стабильных подписей кнопок и индексов телефона. Не удаляйте его без отдельной
процедуры ротации. Не публикуйте `.env` и не включайте payload-логи PyMax.

Один процесс удерживает advisory lock. Отозванная MAX-сессия остаётся отключённой
до повторного входа пользователя. Самостоятельно SMS бот не запрашивает.
