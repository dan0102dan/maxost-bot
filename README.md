# MAXOST

**Ваш MAX — в Telegram.** Диалоги, группы и каналы — в топиках одного бота.

Подключите свой аккаунт по SMS или QR и отвечайте на сообщения прямо в Telegram.

## Возможности

- Переписка и файлы в обе стороны, альбомы, стикеры и форматирование.
- Ответы, редактирование текста и вложений.
- Опросы с голосованием в MAX и отображение реакций.
- Отдельные подключения пользователей, зашифрованные сессии и очередь PostgreSQL.

## Запуск

В **@BotFather** включите топики в личных чатах. У бота не должно быть другого
получателя обновлений или webhook.

```bash
git clone https://github.com/dan0102dan/maxost-bot.git
cd maxost-bot
python3 scripts/configure.py
docker compose up -d --build
```

Скрипт создаст `.env` с токеном и ключами. Откройте бота → `/start` → введите номер
и выберите SMS или **«Войти по QR»**. QR нужно подтвердить в приложении MAX.

Для закрытого доступа задайте `ALLOWED_TELEGRAM_IDS=123,456` в `.env`.
Пустое значение открывает регистрацию всем. По умолчанию: до 100 аккаунтов,
файлы до 20 МБ.

## Команды

| Команда | Действие |
|---|---|
| `/connect` | Подключить MAX |
| `/status` | Проверить подключение |
| `/disconnect` | Отключить MAX и удалить данные сервиса |
| `/delete` ответом | Удалить своё сообщение из MAX |
| `/cancel`, `/help` | Отменить вход, открыть справку |

## Безопасность

**Alpha-версия.** Используется неофициальный PyMax: возможны изменения протокола
и ограничения аккаунта. Оператор сервера имеет технический доступ к переписке;
шифрование БД не является сквозным. Коды входа не сохраняются в БД.

Храните резервную копию `.env` отдельно от БД. Не публикуйте токены и ключи.
