# MAXOST

**Ваш MAX — в Telegram.** Диалоги, группы и каналы — в топиках одного бота.

Подключите аккаунт по SMS или QR и отвечайте прямо из Telegram.

## Возможности

- Сообщения и файлы в обе стороны.
- Альбомы, стикеры, ответы, форматирование и редактирование.
- Нативные Telegram-опросы с голосованием в исходном опросе MAX.
- Нативные реакции там, где платформы позволяют передать их без искажения.
- Отдельная сессия для каждого пользователя, PostgreSQL и зашифрованное состояние.

## Запуск

В **@BotFather** включите топики в личных чатах. У токена не должно быть другого
получателя обновлений или webhook.

```bash
git clone https://github.com/dan0102dan/maxost-bot.git
cd maxost-bot
python3 scripts/configure.py
docker compose up -d --build
```

Откройте бота → `/start` → введите номер → выберите SMS или **«Войти по QR»**.

Для закрытого доступа задайте в `.env`:

```dotenv
ALLOWED_TELEGRAM_IDS=123,456
```

Пустое значение открывает регистрацию всем. По умолчанию: до 100 аккаунтов,
файлы до 20 МБ.

## Команды

| Команда | Действие |
|---|---|
| `/connect` | Подключить MAX |
| `/status` | Проверить подключение |
| `/disconnect` | Отключить MAX и удалить данные |
| `/delete` ответом | Удалить своё сообщение из MAX |
| `/cancel` | Отменить вход |
| `/help` | Справка |

## Безопасность

Используется неофициальный PyMax: протокол MAX может измениться, а аккаунт —
получить ограничения. Оператор сервера технически имеет доступ к пересылаемой
переписке; шифрование БД не является сквозным.

Коды подтверждения не сохраняются. Не публикуйте `.env`, токены и ключи.
